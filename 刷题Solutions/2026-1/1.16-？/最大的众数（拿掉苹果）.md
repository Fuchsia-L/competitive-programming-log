# ACM 练习笔记 (2025-01-21)

## [F] [Gym 106289F - Applejack's Harvest](https://codeforces.com/gym/106289/problem/F) (贪心, 排序, 二分)

* **题目大意**: 有 n 个等级的苹果，第 i 级有 $a_i$ 个。移除恰好 k 个苹果后，求剩余苹果中**众数等级的最大可能值**。多组查询，每次给定不同的 k。

* **核心逻辑**:
  
  **关键观察**: 要让等级 $i$ 成为众数，需要把所有数量比 $a_i$ 大的等级削减到 $\leq a_i$。
  
  **贪心策略**: 
  1. 将所有等级按数量**降序排序**
  2. 从大到小遍历，维护「当前已考虑的等级中，编号最大的 maxid」
  3. 设当前遍历到第 $i$ 个（0-indexed），当前数量为 $c_i$，则让 maxid 成为众数需要移除的苹果数为：
     $$\text{cost} = \sum_{j=0}^{i-1}(c_j - c_i) = i \times (c_0' - c_i)$$
     其中 $c_0'$ 是上一轮的数量（差分思想累加）
  4. 将 `(累计cost, maxid)` 记录到 `book[]` 数组中
  5. 查询时**二分查找**：找到最大的 cost ≤ k 对应的 maxid

  **本质**: 预处理出「移除 x 个苹果能达到的最大众数等级」的分段函数，查询就是在这个函数上二分。

* **总结/关键点**:
  
  | 坑点 | 说明 |
  |------|------|
  | **二分上界** | `book[]` 的有效索引是循环后的 `index`，不是 `n`！当有大量相同值时 `index << n` |
  | **数据类型** | $k \leq \sum a_i \leq 2\times10^{11}$，必须用 `long long` |
  | **$a_i = 0$** | 数量为 0 的等级不可能成为众数，不要放入优先队列 |
  | **相同数量合并** | 多个等级数量相同时，只更新 maxid，不新增 book 条目（`derta != 0` 判断） |
  
  **时间复杂度**: $O(n \log n + q \log n)$
