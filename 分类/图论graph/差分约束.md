# 差分约束 (Difference Constraints)

## 1. 核心思想：不等式变最短路

有一堆变量 x_1, x_2, ..., x_n，约束条件全是 x_v - x_u <= w 的形式。
直接解？没法解。但建成图跑最短路，答案自动出来。

**转化规则**：x_v - x_u <= w → 建一条 u→v 权重 w 的有向边。

**为什么能这么干**：最短路有三角不等式 dist(v) <= dist(u) + w，移项就是 dist(v) - dist(u) <= w。和差分约束的形式一模一样。所以令 x_i = dist(source → i)，所有约束自动满足。

## 2. 松弛的直觉

所有变量初始值 = 正无穷。每条边都是一只手在往下压变量：

"我是边 u→v 权重 w，我要求 x_v <= x_u + w，你现在太高了，给我下来。"

反复压，直到没有任何边能再压为止。最终每个变量停在的位置 = 满足所有约束的最大值。

- 最短路（往下压）→ 每个变量的上界（最大值）
- 最长路（往上抬）→ 每个变量的下界（最小值）

## 3. 负环 = 无解

负环意味着一圈约束加起来要求 0 <= 负数，矛盾。

例：x_2 - x_1 <= 3, x_3 - x_2 <= -5, x_1 - x_3 <= 1
加起来：0 <= -1，爆炸。

检测方法：Bellman-Ford 松弛 n 轮后还能更新 = 有负环。

## 4. 建图模式

### 绝对值约束 |x_u - x_v| <= w
拆成两条：
- x_v - x_u <= w → u→v 权重 w
- x_u - x_v <= w → v→u 权重 w

### 精确约束 x_v - x_u = w
拆成两条：
- x_v - x_u <= w → u→v 权重 w
- x_u - x_v <= -w → v→u 权重 -w

### 下界约束 x_v - x_u >= w
翻转成 x_u - x_v <= -w → v→u 权重 -w

## 5. 例题：CF1450E Capitalism (rating 2700)

### 题意
n 个人构成无向连通图，每条边的两端收入差恰好为 1。部分边指定了方向（谁比谁多 1），其余不限。求最大收入差。

### 建图
- 有向边 u→v（u 羡慕 v，a_v = a_u + 1）：
  - u→v 权重 1（a_v - a_u <= 1）
  - v→u 权重 -1（a_u - a_v <= -1）
  - 合起来 = a_v - a_u 恰好等于 1
- 无向边 u-v（不知道方向）：
  - u→v 权重 1（a_v - a_u <= 1）
  - v→u 权重 1（a_u - a_v <= 1）
  - 合起来 = |a_v - a_u| <= 1，二部图保证不为 0，所以恰好为 1

### 解法
1. 判二部图（相邻节点奇偶不同）：不是二部图 → 无解
2. Floyd-Warshall 跑全源最短路（n <= 200 所以 O(n^3) 够用）
3. 检查负环：对角线 dist[i][i] < 0 → 无解
4. 找直径：max(dist[u][v])，就是最大收入差
5. 赋值：选直径端点 u，令 a_i = dist(u → i)

### 为什么这样赋值是对的
- 最短路保证所有约束成立
- 二部图保证相邻点不会被赋相同值（奇偶性不同）
- 选直径端点保证差值最大

## 6. 易错点

- [ ] 差分约束的边可以有负权，不能用 Dijkstra，要用 Bellman-Ford / SPFA / Floyd-Warshall
- [ ] 图可能不连通：加一个超级源点 s，向所有点连权重 0 的边
- [ ] 最大化用最短路，最小化用最长路，别搞反
- [ ] Floyd-Warshall 检测负环看 dist[i][i] < 0
