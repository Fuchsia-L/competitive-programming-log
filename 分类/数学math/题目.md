# Game on Board

## 基本信息
- **题目链接**: https://qoj.ac/contest/2559/problem/14425
- **难度**: （实现不难。但思路就不一定了）

## 题目大意
棋盘上有 n 个不同正整数，三个玩家轮流操作。每次选两个数 x, y，若 |x-y| 不在棋盘上则写上去。无法操作者输。问玩家 2 和 3 合作能否让玩家 1 输。

## 信号识别
- 操作是"两数相减" → 辗转相减 → gcd
- 问的是"最终状态"或"总步数" → 最终状态可由 gcd 直接算出，不用模拟

## 解题思路
相减操作的本质是辗转相减。所有能产生的数都是原数组 gcd 的倍数，且 gcd 一定能被造出来。最终棋盘上的数是 g, 2g, 3g, ..., max，共 max/g 个。

总步数 = max/g - n，mod 3 判断谁输。

## 最终实现
1. 遍历数组，求所有数的 gcd 和 max
2. 计算 ans = max / gcd - n
3. ans % 3 == 0 输出 YES，否则 NO

## 易错分析
- [ ] 数据范围 10⁹，不能枚举，直接用公式
- [ ] 条件是 `% 3 == 0`（玩家1先手无法动）
