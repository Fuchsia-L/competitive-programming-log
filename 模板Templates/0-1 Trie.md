# 算法笔记：0-1 字典树 (Binary Trie)

## 1. 核心思想：把"位"摆成树

普通字典树存字符串，每层一个字符。**0-1 Trie** 把整数当成**固定位宽**（K 位，高位在上）的二进制串存进二叉字典树：每层只有两个分支，0 走左、1 走右。

```
       root (depth=K)
       /        \
      0          1     ← 第 K-1 位 (MSB)
     / \        / \
    0   1      0   1   ← 第 K-2 位
   ...        ...
```

任意整数 $x$ 都对应根到叶的唯一一条长度 $K$ 的路径。

### 为什么 0-1 Trie 能秒杀"最大异或"？
- 异或最大化是**逐位贪心**问题：从最高位开始，**每一位都希望两个数在该位不同**（这样 XOR 出 1）。
- Trie 把"已有数"按位组织好了，查询时从根开始：当前 $x$ 在这一位是 $b$，**优先走 $b \oplus 1$ 那个分支**（拿到该位的 1）；走不动再退而求其次走 $b$（该位贡献 0）。
- 这是 K 步的贪心，不会回头——**就是最优解**，因为高位的 1 抵得过所有低位的总和。

## 2. 两个核心操作

### Insert(x)：O(K)
从根出发，按 $x$ 从高到低的每一位走/建节点。每经过一个节点 `cnt++`（如果要支持删除）。

### Query_max(x)：O(K)
从根出发，对每一位：
1. 想走反位 `b ^ 1`：若该子节点存在且 `cnt > 0`，就走，结果该位置 1
2. 否则只能走同位 `b`：该位结果置 0

最终走完 K 步得到的 `res` 就是已插入的数与 $x$ 配出的最大 XOR。

### Erase(x)：O(K)（可选）
按 $x$ 的位走一遍，沿路 `cnt--`。**不要真删节点**——节点空间复用即可，重要的是 `cnt` 控制"逻辑上还有没有这个数"。

## 3. 经典模型：最大子段异或

> 给定数组 $a[1..n]$，求一个连续子段使其元素异或最大。

### 套路
1. 定义前缀异或 $p[0]=0$，$p[i] = a[1] \oplus \dots \oplus a[i]$
2. **关键恒等式**：子段 $a[l..r]$ 的 XOR = $p[r] \oplus p[l-1]$
3. 问题变成：在集合 $\{p[0], p[1], \dots, p[n]\}$ 中选两个数异或最大

### 算法
```
trie.insert(0);              // p[0]
p = 0; ans = 0;
for i = 1..n:
    p ^= a[i];               // 当前 p[i]
    ans = max(ans, trie.query_max(p));   // 找已有 p[j] (j<i)
    trie.insert(p);
```

复杂度 $O(nK)$，$n=10^5$、$K=30$ 时约 $3 \times 10^6$，稳过。

### Q：为什么 query 出来的对必然是"连续子段"？
配上的两个值是 $p[i]$ 和某个之前插入的 $p[j]$ ($j < i$)。它们异或 = 子段 $a[j+1..i]$ 的异或——**天然连续**，不需要额外约束。Trie 的"无序集合"性质和子段的"连续"要求在前缀异或这里**自动桥接**。

## 4. 变体识别：什么时候上 0-1 Trie？

| 题型信号 | 解法 |
|---|---|
| 最大子段异或，$a_i < 2^8$ ~ $2^{20}$（值域小） | 暴力对，$O(\|S\|^2)$ |
| 最大子段异或，$a_i < 2^{30}$（值域大） | **0-1 Trie** |
| 多重集合，支持插入 / 删除 / 查与 $x$ 异或最大 | **0-1 Trie + cnt** |
| 选若干元素异或最大（无连续要求） | **线性基**（这是另一个东西，不要混） |
| 求异或第 k 大 / 第 k 小 | Trie + 子树计数 |

## 5. 踩坑记录 (Post-Mortem)

### 🛑 坑点 1：多测忘记清空
`tot` 和 `ch[][]` 跨测试用例共享会污染上一组数据。
- **修正**：开头调 `trie.clear()`。或者更简单：每组重新构造一个 Trie 对象（如果不嫌慢）。

### 🛑 坑点 2：节点数开小
插入 $n$ 个 K 位的数，最坏要 $n \cdot K$ 个节点。
- $n=10^5, K=30 \Rightarrow 3 \times 10^6$ 节点
- 每节点 `ch[2]` 是两个 int（8 字节），$3 \times 10^6 \times 8 = 24$ MB，**贴着内存限制**
- **修正**：按题目 $n$ 上限 `assign`，不要一律开 1e7

### 🛑 坑点 3：忘记插入 `p[0] = 0`
不插的话漏掉"从 a[1] 开始的子段"——子段长度 $r$ 对应 $p[r] \oplus p[0]$。
- **修正**：算法开头先 `trie.insert(0);`

### 🛑 坑点 4：先 insert 再 query 的顺序
应该 **先 query 再 insert**：
```cpp
ans = max(ans, trie.query_max(p));  // 找之前的 p[j], j < i
trie.insert(p);                      // 再把 p[i] 放进去
```
反过来的话 query 可能匹配到自己（$x \oplus x = 0$），虽然不会让答案变小，但语义不对，养成习惯。

### 🛑 坑点 5：K 选错
- `int` 范围内的非负整数：K=30
- 异或链可能溢出：注意 long long，K=60
- 题目给 `a_i < 2^B`：K 取 B（前缀异或不会扩位宽）

## 6. 与"线性基"的区分

两者都是位运算结构，但解决的问题不同：

| | 0-1 Trie | 线性基 |
|---|---|---|
| 解决 | 与某个 $x$ 异或**最大**的元素 | 选**任意子集**异或最大 |
| 是否支持原元素查询 | 是（存的就是原值） | 否（存的是基向量） |
| 支持删除 | 是（cnt 计数） | 难（要重建） |
| 子段最大异或 | ✅（搭配前缀异或） | ❌（线性基允许任选子集，破坏了"连续"） |

**口诀**：要"原数对"用 Trie，要"子集异或"用线性基。
